# Robotics Tool 개발 계획

> 목표: **노트북 없이 폰 하나로 ROS2 로봇 상태를 빠르게 확인하는 Android 앱**
> 판단 기준: "현장에서 로봇 옆에 서서 폰으로 3초 안에 상태를 파악할 수 있는가"

## 1. 현황 점검 결과 (2026-09)

`tool/e2e/`의 가짜 rosbridge 서버(16개 토픽, 12개 노드)로 모든 화면을 띄워 확인했다.

### 치명적 (앱이 동작하지 않음)
| 문제 | 원인 |
|---|---|
| LaserScan 화면이 회색으로 멈춤 (예외 49회) | rosbridge는 `inf`/`NaN` 거리를 `null`로 보내는데 `(e as num)` 캐스팅에서 예외 |
| 데이터가 끊겨도 Hz가 그대로 표시 | Hz가 "첫 메시지 이후 전체 평균"이고, 메시지가 올 때만 갱신됨 |
| Odometry 첫 메시지가 그래프에 안 들어감 | `initState`에서 처리하지 않고 `didUpdateWidget`에서만 처리 |

### 가독성 (시각화)
| 화면 | 문제 |
|---|---|
| LaserScan | 레이더 차트라 36개 점으로 뭉개지고, 0°가 아래쪽이라 로봇 전방을 알 수 없음. 거리 단위/눈금 없음 |
| Odometry | XY 궤적의 가로세로 비율이 달라 모양이 왜곡됨. 축 라벨이 겹침(`1122`), 속도 그래프에 범례·단위 없음 |
| Twist | 막대 게이지 범위가 ±2로 고정, 축 라벨이 막대와 겹침, 항상 0인 축(y, z)도 모두 표시 |
| Float32 등 스칼라 | Y축 라벨이 두 줄로 깨짐(`12.32 / 9`), 작은 노이즈가 과장되게 보임, 시간축 없음 |
| Imu / JointState / BatteryState / Range / String / Bool | 전용 화면 없이 JSON 트리만 표시 |
| Node Graph | 화면 전체에 맞추느라 글자가 읽을 수 없을 만큼 작음 |
| 공통 | 시각화 화면에서 원본 JSON을 볼 방법이 없음. 시간축이 "메시지 번호"라 실제 시간과 다름 |

### UI 친절함
| 화면 | 문제 |
|---|---|
| 연결 | 동작하지 않는 `ROS_DOMAIN_ID` 입력칸, 최근 연결 목록 없음, 실패 시 원인 안내 없음 |
| 토픽 목록 | 토픽을 누르면 매번 메뉴를 한 번 더 거쳐야 함, `/rosout` 같은 시스템 토픽이 섞임, 타입별 개수 없음 |
| 전체 | 메인 화면에서 연결 상태(재연결 중 등)를 알 수 없음 |
| Publish | 반복 발행 시 "Published!" 스낵바가 계속 뜸, 연결이 끊겨도 성공으로 표시, JSON 직접 입력만 가능 |
| Graph | "Highlight in Graph"를 눌러도 Graph 탭으로 이동하지 않음, 연결 후 한 번만 불러옴 |
| 설정 | 버전이 코드에 하드코딩(`1.0.3`) |

## 2. 개발 단계

각 단계는 **analyze 무경고 → 단위/위젯 테스트 → 가짜 서버 E2E(예외 0건 + 스크린샷 확인)** 를 통과해야 커밋한다.

### Phase 1. 안정성과 신뢰성
- [ ] 모든 시각화에서 메시지 숫자 파싱을 안전하게(`null`, 문자열, 정수/실수 혼용) — 공용 헬퍼로 통일
- [ ] Hz를 최근 구간(슬라이딩 윈도우) 기준으로 계산하고, 일정 시간 데이터가 없으면 **"No data 3.2s"** 경고 표시
- [ ] 일시정지 시 Hz/상태 표시 정리, Odometry 첫 메시지 처리
- [ ] Publish: 연결 끊김 시 실패 표시, 반복 발행 스낵바 제거·발행 횟수 표시

### Phase 2. 시각화 가독성
- [ ] **공용 시계열 차트**: 실제 시간축(초), 범례+현재값, 단위, 겹치지 않는 축 라벨, 노이즈 과장 방지(최소 표시 범위)
- [ ] **LaserScan**: 로봇 중심·전방 위쪽의 2D 평면도, 미터 눈금 링, 거리별 색상, 확대/축소, **최근접 장애물 거리·방향**
- [ ] **Odometry**: 1:1 비율 궤적 + 현재 자세 화살표, 선속도/각속도 차트
- [ ] **Twist**: 로봇 기준 방향 표시 + 차트, 항상 0인 축 자동 숨김
- [ ] **새 전용 화면**: Imu(자세 roll/pitch/yaw + 각속도/가속도), JointState(관절별 표), BatteryState(잔량·전압·상태), Range, String/Bool, Pose/PoseStamped, 모든 std_msgs 숫자 타입
- [ ] 모든 시각화에 **Visual / Raw JSON** 전환
- [ ] Image: 깊이 영상(16UC1, 32FC1, mono16) 지원

### Phase 3. UI 친절함과 현장 기능
- [ ] 연결 화면: 가짜 `ROS_DOMAIN_ID` 제거, 최근 연결 목록, 입력 검증, 실패 원인 안내
- [ ] 토픽 목록: 탭하면 바로 Echo, 타입 아이콘/개수, 시스템 토픽 숨김
- [ ] 메인 화면 상단 연결 상태 배너(재연결 중 / 끊김)
- [ ] Graph: 휴대폰에서 읽을 수 있는 크기, 노드 탭 시 발행/구독 목록, Highlight 시 탭 전환
- [ ] Twist 발행용 **가상 조이스틱**(손을 떼면 즉시 정지 명령 전송)
- [ ] 설정: 앱 버전 자동 표시

### Phase 4. 품질 인프라
- [ ] `test/`: 파싱 헬퍼, Hz 계산, 스캔 좌표 변환, Provider 상태 전이, rosbridge 서비스(로컬 WebSocket 서버) 테스트
- [ ] `tool/e2e/`: 가짜 rosbridge 서버 + Playwright 시나리오/전체 화면 캡처
- [ ] GitHub Actions: analyze + test + debug APK 빌드(아티팩트로 다운로드해 실기기 테스트)
- [ ] README 갱신

## 3. 검증 환경

- **로컬(클라우드 컨테이너)**: Flutter SDK, 웹 빌드 + Chromium + 가짜 rosbridge 서버
- **CI**: GitHub Actions에서 Android APK 빌드 (컨테이너에서는 Android SDK를 받을 수 없음)
- **실기기**: CI가 만든 APK를 휴대폰에 설치해 실제 ROS2 + rosbridge로 최종 확인 (개발자 직접)
